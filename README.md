-Microsoft Excel
-Pivot Tables

## Project Overview

This project demonstrates how Microsoft Excel can be used to clean, analyze, and visualize healthcare data.

The dataset contains patient information including:

Patient ID
Age
Gender
Doctor
Diagnosis
Treatment
Visit Date
Treatment Cost

The objective was to transform messy raw data into meaningful business insights using Excel.
